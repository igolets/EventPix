# mono

A dark, editorial second theme. It exists to prove the theming contract ([docs/architecture.md § 8](../../docs/architecture.md#8-theming-contract)):
same `data-tpl` / `data-ref` / `data-i18n` hooks as `default`, completely different markup, class names and CSS.
Core JS and C# are untouched - switching themes is one setting:

    EventPix__ActiveTheme=mono
